  Edit in the builder

Characters in your three.js app.

One call builds a realistic, rigged and animated character on your users' devices: choose a preset, a random seed or a builder share link, add props, colours and animations, and drop it into your scene.

import { createCharacter } from 'ara3d';

const hero = await createCharacter('The Soldier', {
  animations: ['rifle_idle'],
  weapon: 'rifle',
});
scene.add(hero.scene);
Library guide

On any web page, with one tag.

No build tools and no 3D code: paste two lines into plain HTML, WordPress, Webflow or any framework. In the builder, Share then Copy embed code gives you the tag for your own character.

<script type="module" src="https://cdn.jsdelivr.net/npm/ara3d@0/dist/embed.js"></script>

<ara-character preset="The Priest" animation="walk 3s, look_around, talk_gestures" expression="happy"></ara-character>

What people build with it

Games and crowds

Heroes, enemies and whole streets of NPCs from presets or seeds. Set a speed and they walk or run in step with the ground.

Talking characters

Expressions, natural blinking, a head that turns to look at things, and lip-sync straight from any audio or microphone. Pair with any voice or AI.

Avatars and try-on

Let users design someone in the builder, then load their share link straight into your app.

Asset pipelines

Generate GLB, FBX or OBJ in CI for Unity, Unreal, Godot or Blender, from small character files kept in Git.

AI assistants

Connect Claude, Cursor or VS Code with npx ara3d mcp and ask for characters in plain words. Published JSON schemas keep what they design valid.

Prototypes

A believable cast for a pitch, a demo or a game jam in minutes, without a 3D artist.

Prefer files? Use the command line.

The same characters as GLB, FBX, OBJ or ZIP, built on your machine. The first run downloads the data once; after that it works offline.

Command-line guide 
# a hero with a rifle, walking and running
$ npx ara3d export --preset "The Soldier" --weapon rifle --animations walk,run
# 200 townsfolk for a crowd
$ npx ara3d export --random 1-200 --detail low --no-animations
# your own character, as a file you can keep in Git
$ npx ara3d new hero && npx ara3d export --params hero.json --formats glb,fbx

Or just ask your AI assistant.

Add Ara to Claude, Cursor or VS Code with one line, then ask for characters in plain words. The assistant designs them, builds them on your machine and hands back the files, with a link to keep editing in the builder.

claude mcp add ara3d -- npx -y ara3d mcp
